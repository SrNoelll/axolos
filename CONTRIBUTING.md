# Contributing to AxolOS

Thank you for helping! Issues and pull requests are welcome in English, Español, Français, Русский,
中文 or 日本語. (Code comments and the technical docs are in Spanish.)

## Before you start

- **Bugs and ideas:** open an [issue](https://github.com/SrNoelll/axolos/issues/new/choose) with the
  template. For security problems, see [SECURITY.md](SECURITY.md) instead.
- **Technical documentation:** [`docs/DESARROLLO.md`](docs/DESARROLLO.md).

## Changing the code

- Each package lives in `packages/<name>/` with its `PKGBUILD`. **Do not bump `pkgrel` by hand**:
  the publication compares every package with the published one and bumps it only if its content changed.
- The look is generated by tools in `tools/` (wallpapers, Plasma frames, Kvantum, colors, window
  decorations, icons). Change the generator, run it and commit both.
- Shell scripts must pass `bash -n`; Python must compile; `.desktop` files must pass `desktop-file-validate`.
  The [checks workflow](.github/workflows/comprobar.yml) runs all of this on every pull request.

## Translations

AxolOS speaks English, Español, Français, Русский, 简体中文 and 日本語.

- Programs (Python and shell): original texts in Spanish, marked with `_()` (or `t` in shell).
  Catalogs in `packages/axolos-branding/po/`.
- The Bento menu (QML): original texts in English, `i18n()`. Catalogs in `packages/axolos-menu/po/`.
- After changing texts: `tools/i18n.sh` updates the templates and catalogs; `tools/i18n.sh --comprobar`
  fails if anything is untranslated. Never use `_` as a variable name (it hides the translation;
  `tools/i18n_sombras.py` checks it).

## Commits

Small, focused commits with a clear message (Spanish or English). Pull requests run the same checks
as the main branch.
